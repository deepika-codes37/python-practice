# BMI Calculator – Advanced Python Project

A beginner-friendly Python project that calculates BMI from height and weight.
This is a simple python BMI calculator project that I made while practicing python.

## Features

* Calculate BMI using height and weight
* Input validation using exception handling
* BMI category classification
* Multiple calculations in one session
* Shows calculation history
* Uses Python functions, loops, dictionaries, and conditionals

## Concepts Used

* Python Functions
* "if-else" Conditions
* "while" Loops
* Dictionaries
* Lists
* Exception Handling
* User Input
  
## How to Run

Make sure Python is installed on your computer (like IDLE/in VSCODE).
Run the program using:

----------------------------
python bmi_calculator.py
----------------------------
Then enter the requested details.

Welcome to the BMI Calculator!!!!!
